# A33：双 KV 页循环展开（2026-10-28）

## 候选

在 A20 页对齐 decode attention 中，每次循环处理两个 KV 页，减少页循环分支并增加 K/V 加载并行度。在线 softmax 顺序、NSEG、combine 和数值语义不变，默认 `unroll_pages=1`，实验显式设置 2。

实验分支：`exp/a33-page-unroll`。基线为当前 A31 集成，不包含 A30。
