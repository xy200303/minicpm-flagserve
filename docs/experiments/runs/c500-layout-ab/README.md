# 单 nn 布局默认值实验（未采纳，2026-11-16）

在同一交付栈上把单布局设为默认（commit `d69e766`，`VLLM_FL_FREE_NT_WEIGHTS=1`、`VLLM_FL_NN_MIN_M=0`）后重跑官方用例，用于判定首次 A/B 的 +0.3% 是否可复现。

## 结果

| 项 | 双布局（交付默认，`58b750e`） | 单布局（`d69e766`） |
|---|---:|---:|
| 4k 后三轮均值 | 12450.37 | **12451.84**（+0.01%） |
| 16k 后三轮均值 | 11095.14 | **11097.29**（+0.02%） |
| KV 池 | 1,111,744 | 1,203,904 tokens |
| 冷启动 | 124 s | 124 s |

首次 A/B（同会话、显式环境变量）曾显示单布局 16k 11130.01、4k 12485.28；把默认值改成单布局后不再复现。判定为跨次波动，**回滚默认值**（`ef0bbe6`，注释更新见 `941fe10`）。

## 为什么保留记录

单布局确实能释放约 4 GB 权重副本并把 KV 池扩大约 8%（`1,111,744 → 1,203,904`），但两场景官方指标没有可复现收益；同时它会把 `layer.weight.data` 置为空存储、改变 `Parameter` 形状，收益不足以承担这个风险。
